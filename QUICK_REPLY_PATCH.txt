Settings: Prome > Sheld Configuration
- Desktop/mobile Quick Reply row limits remain configurable.
- Apply mobile layout at height (px): default 1000. Mobile row count is used
  when the visible window HEIGHT is at or below this threshold. This replaces
  v1's fixed width threshold. Slider + number field + Reset; range 100-3000px.
- Sheld window height (%): default 0 (Automatic, original ST/theme height).
  Slider + number field + Reset; 1-100 sets percentage of visible window height.
  Applies in VN mode. Default removes the override instead of assuming a fixed
  height for every theme. Keyboard/viewport resize updates the custom height.
